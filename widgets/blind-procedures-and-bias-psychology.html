Blinding does not kill the placebo effect, it makes it cancel

Blinding gets described as if it deletes the placebo effect. It does not: people who expect to improve still improve. What a good procedure does is give both groups the same expectation, and stop the person scoring the results from knowing which score the hypothesis wants to win. Know This

Single-blind hides the allocation from participants; double-blind hides it from the experimenter too, yet neither removes the placebo effect: the placebo group is there so it cancels.
