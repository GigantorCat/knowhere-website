Direct testing measures the actual performance outcome in real conditions — a 3km time trial for a distance runner, a 1RM squat for a powerlifter, a Yo-Yo test for a footballer. These tests have high validity because they mirror the sport demands exactly. The downside? They require full effort, create fatigue, and need careful recovery planning. You're essentially asking the athlete to perform at competition intensity just to get data. Some direct tests also require expensive equipment or controlled environments — VO₂ max testing in a lab, for instance, is the gold standard for aerobic capacity but needs a metabolic cart and trained technicians.

Know This

Activity analysis identifies the specific physiological demands of a sport, which then determines which fitness components need testing — only then can you select valid and reliable tests that actually measure what matters for performance.
