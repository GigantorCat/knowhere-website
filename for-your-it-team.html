A teacher at your school is using knowhere · teach it., an Australian Year 11 and 12 teaching tool (HSC and VCE). It runs entirely in the browser — on the teacher's laptop on the projector, and on students' laptops when a teacher shares a slide or a homeplay task. There is no app, no plug-in, no extension and no student account for shared links.

Category

If your filter (Linewize / Smoothwall, Netsweeper, FortiGuard, Cisco Umbrella, Zscaler, GoGuardian, Securly, Lightspeed) has knowhere.me uncategorised or filed as "new site", please file it under Education. Some vendors take a re-categorisation request from anyone; Zscaler, GoGuardian, Securly and Lightspeed only take one from your own admin console. Either way, the one-liner below is what to paste.

knowhere.me and app.knowhere.me — Australian education site for HSC and VCE (Years 11–12): interactive study and classroom teaching tool used by teachers and students. Please categorise as Education. Contact: hello@knowhere.me

Steps for your filter

The fastest fix is an allow rule. Some filters treat knowhere.me and app.knowhere.me as separate sites, so add both (or *.knowhere.me where wildcards work).

FilterWhere to allow it
Linewize (Qoria)Allow both in the students' filtering policy. To fix the category for every school: Filtering → Content Filtering → Category Search → Suggest a category → Education.
Smoothwall (Qoria)Add both to an allow list in your web filter policy.
ZscalerAdministration → URL Categories: add both to a custom category, then allow it in Policy → URL & Cloud App Control. Zscaler only re-categorises for customers, so if you can, request Education from your admin portal too.
GoGuardian AdminQuick Editor → + Enter a URL → Allow → pick the policy your students are on. Add each domain on its own: a domain rule doesn't cover its subdomains. Allow up to 15 minutes.
SecurlyPolicy Editor → Global Settings → Allow/Block → URL: add knowhere.me and *.knowhere.me. Or use the allow list on one policy.
Lightspeed FilterAdd both as Allow in a web rule and apply it to the rule set your students use.
NetsweeperAllow both in your policy, or raise a category review with Netsweeper support from your account.
FortiGate (FortiGuard)Web filter profile → URL filter: add both as Allow. Category review: fortiguard.com/webfilter.
Cisco UmbrellaPolicy Components → Destination Lists: add both to an allow list on the students' policy.

Not listed? Look for “allow list”, “whitelist” or “URL override” in your filter's policy settings. The domains above are all it needs.

The quick test. From a student laptop on the school network, open knowhere.me/join?test=1. If it says “You're through.”, you're done. If a block page shows instead, the filter is catching one of the domains above.
